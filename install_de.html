TandaComposer
einrichten

TandaComposer wird über einen macOS-Installer installiert. Die App wird dabei automatisch in den Programme-Ordner kopiert.

Voraussetzung: macOS Sequoia (15) oder neuer, Apple-Silicon-Mac (M1 oder neuer). Intel-Macs werden nicht unterstützt.

15+

macOS Sequoia

Erster Start

TandaComposer öffnen normaler Start

Öffne den Programme-Ordner und starte TandaComposer mit einem Doppelklick.

  1. Programme öffnen

    Öffne im Finder den Ordner Programme und suche nach TandaComposer.

  2. TandaComposer starten

    Doppelklicke auf TandaComposer.app.

  3. Mögliche Sicherheitsmeldung

    Da TandaComposer nicht über den Apple App Store verteilt und nicht mit einer kostenpflichtigen Apple-Developer-ID signiert ist, kann macOS beim ersten Start eine Sicherheitsmeldung anzeigen.

    Das ist bei dieser Installationsart normal. Die Meldung bedeutet nicht, dass die Installation fehlgeschlagen ist.
Falls macOS den Start blockiert

App trotzdem öffnen macOS Sicherheit

Falls macOS TandaComposer beim ersten Start blockiert, kann die Freigabe über die Systemeinstellungen erfolgen.

  1. Warnung schließen

    Wenn macOS meldet, dass TandaComposer nicht geöffnet werden kann, schließe den Dialog zunächst.

  2. Datenschutz & Sicherheit öffnen

    Öffne Apple-Menü → Systemeinstellungen → Datenschutz & Sicherheit.

  3. Bereich „Sicherheit“ prüfen

    Scrolle im Bereich Sicherheit nach unten. Wenn macOS TandaComposer blockiert hat, kann dort eine entsprechende Meldung mit einer Option zum Öffnen der App erscheinen.

  4. Öffnen bestätigen

    Wähle die angebotene Option zum Öffnen von TandaComposer und bestätige die Sicherheitsabfrage.

    Danach: TandaComposer kann wie gewohnt aus dem Programme-Ordner gestartet werden.
Wichtig

Installation und App Hinweis

Der Installer hat die App bereits an den vorgesehenen Ort kopiert. Eine zusätzliche Kopie oder ein separates Freischalt-Skript ist nicht erforderlich.

  1. Keine Dateien neben der App notwendig

    TandaComposer benötigt nach der Installation weder eine .command-Datei noch weitere Installationsdateien.

  2. App nicht aus dem Installer starten

    Nach Abschluss der Installation sollte TandaComposer aus dem Programme-Ordner gestartet werden.

  3. Installationshilfe

    Diese Anleitung wurde automatisch nach Abschluss der Installation geöffnet. Eine Kopie befindet sich außerdem innerhalb der TandaComposer-App.
