Installation Guide

Setting up
TandaComposer

TandaComposer is installed using a standard macOS installer. The application is automatically copied to your Applications folder.

Requires: macOS Sequoia (15) or later, Apple Silicon Mac (M1 or later). Intel Macs are not supported.

⌘

Apple Silicon

TandaComposer is optimized for Apple Silicon Macs and supports M1, M2, M3, M4 and later Apple processors.

15+

macOS Sequoia

macOS 15 (Sequoia) or a newer version of macOS is required.

First Launch

Open TandaComposer Normal launch

Open the Applications folder and launch TandaComposer with a double-click.

  1. Open Applications

    In Finder, open the Applications folder and locate TandaComposer.

  2. Launch TandaComposer

    Double-click TandaComposer.app to start the application.

  3. Possible security warning

    Because TandaComposer is distributed outside the Mac App Store and is not signed with a paid Apple Developer ID, macOS may show a security warning the first time you launch it.

    This is normal for this type of distribution. It does not mean that the installation failed.
If macOS blocks the app

Allow TandaComposer to open macOS Security

If macOS blocks TandaComposer on its first launch, you can allow the application through System Settings.

  1. Dismiss the warning

    If macOS says that TandaComposer cannot be opened, close the dialog first.

  2. Open Privacy & Security

    Open Apple menu → System Settings → Privacy & Security.

  3. Check the Security section

    Scroll down to the Security section. If macOS has blocked TandaComposer, a corresponding message may appear there together with an option to allow the application to open.

  4. Confirm the launch

    Select the available option to allow TandaComposer to open and confirm the security prompt if requested.

    After that: TandaComposer can be launched normally from the Applications folder.
Important

Installation and application Note

The installer has already copied the application to its intended location. No additional copy or separate unlock script is required.

  1. No additional files are required

    After installation, TandaComposer does not require a .command file or any other installation files next to the application.

  2. Launch the application from Applications

    After installation, TandaComposer should be launched from the Applications folder.

  3. Installation guide

    This guide was opened automatically when the installation completed. A copy is also included inside the TandaComposer application.

Ready

Enjoy TandaComposer

The installation is complete. You can now launch TandaComposer from your Applications folder and start using it.
